# SWYNEX Internship - Task 1: Biological Dataset Selection
### 1. Dataset Details
- Dataset Name: Expression data from Breast cancer subtypes
- Accession ID: GSE45827
- Repository: NCBI GEO
- URL: https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE45827
### 2. Description
155 samples: 41 TN, 30 HER2, 29 Luminal A, 30 Luminal B, 11 normal. Homo sapiens. Affymetrix GPL570 Array.
### 3. Size and Format
Samples 155, Format CEL/TXT, Size ~60MB, Access Public
